The Local AI Starter Kit

Run capable AI on your own hardware — no cloud, no per-token bills

Why go local

  • Cost: Cloud frontier models bill per token. Local = one-time hardware cost, unlimited runs.
  • Reliability: OpenAI/Anthropic have had repeated outages. Your local model never goes down.
  • Privacy: Your data never leaves your machine. No prompts sent to a third party.
  • Speed: No network round-trip. Instant responses on-device.
  • Capability: Modern local models are genuinely impressive — in Sept 2026 a local Fable model cracked a 370-year-old unsolved cipher on modest hardware.

Install in 15 minutes

  1. Install Ollama (free, open-source): curl -fsSL https://ollama.com/install.sh | sh
  2. Pull a small model: ollama pull deepseek-r1 (or phi4)
  3. Run it: ollama run deepseek-r1
  4. Optional GUI: Open WebUI (free) for a ChatGPT-like interface

When local beats cloud (and when it doesn't)

Local wins: privacy-sensitive data, high-volume repetitive tasks, offline work, cost control.

Cloud still wins: massive context windows, cutting-edge reasoning, image/video gen at scale.

The smart play: hybrid

Run local for the 80% of everyday tasks. Use cloud only for the 20% that needs frontier power. Cut your AI bill by up to 90%.
